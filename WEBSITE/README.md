# Sai Ram Das — Personal Portfolio (Simple Version)

A simple, 3-page responsive personal website built with semantic HTML5, Flexbox, CSS Grid, CSS variables, and media queries.

## Project Structure

```
my-website/
├── css/
│   └── style.css        # Colors (variables), flexbox nav, grid layouts, media queries
├── js/
│   └── main.js           # Mobile nav toggle + demo contact form message
├── images/                # (empty — visuals are done in CSS for now)
├── pages/
│   ├── about.html
│   └── contact.html
├── index.html             # Home page
└── README.md
```

## Pages
- **Home** — short intro + quick facts
- **About** — bio, KL University details, skills
- **Contact** — email, Instagram, and a simple contact form

## How to Run
Just open `index.html` in any browser — no build step needed. Keep the `css/` and `js/` folders next to the HTML files so styling and the mobile menu work correctly.

## Responsiveness
- **Mobile:** ≤ 768px (nav collapses into a toggle menu)
- **Tablet:** 769px – 1024px
- **Desktop:** > 1024px
